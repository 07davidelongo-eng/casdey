## Why this replaced the dental skill, and what's different
**FULL AUTOMATION as of 2026-08-28 — the human review gate is removed.** Davide reviewed the daily 5-7 draft samples every day from 2026-08-24 through 2026-08-28, judged the copy consistently good ("really close to what I wrote... it's perfect"), and made the explicit, deliberate call to remove the pre-send approval step entirely. The Routine now runs Step 0 → Part A → Part B (send) → Step R (report) end to end on every fire, unattended, no pause. This is a knowing reversal of the 2026-08-22 hybrid design below; it is exactly the "Davide explicitly revisits that call" condition the old "don't quietly revert to autonomous sending" rule reserved. What still protects sends without a human: opt-out exclusion from Step 0, dedup against `Send Log`, the exactly-50/day cap, and hard pre-send content gates (word count, no em dash, no offer/link, non-empty subject+body) that skip any bad draft rather than send it. The residual risk Davide accepted: a prompt-injection during Part A's live web sourcing no longer has a human review catching a bad draft before it goes out, only those automated gates. See "Fully automated sending" and "Reporting" below for the current flow.

The dental cold-outreach skill (`.claude/skills/cold-outreach/`, now marked retired) ran fully unattended: an AI Routine sourced, drafted, and sent up to ~20 emails a day with no human review. 216 sends produced 0 genuine replies. The go-to-market plan drafted afterward (CLAUDE.md) concluded that volume without a human in the loop was itself part of the problem, not just the message, and calls for a manual/relationship-first approach for gyms: small batches, real review, direct conversations, feedback collected at every step. Davide confirmed this on 2026-08-22 with a **hybrid** model (superseded 2026-08-28, see the banner above — kept here as the design history):
- **Automated**: lead sourcing and first-draft email copy.
- **Manual (until 2026-08-28)**: the actual send. Every batch was reviewed (and could be edited) by Davide/Abhi before anything went out.

Email/community-DM outreach (Instagram, Facebook/Slack groups) that the go-to-market plan also calls for is Davide's own manual track, outside this skill's scope — this skill only covers the email channel, where casdey already has sending infrastructure.

**Enforcement mechanism changed 2026-08-23 — read this carefully, it's a real posture shift, not just a cleanup.** From 2026-08-22 to 2026-08-23 the "manual send" rule above was backed by a hard technical gate: sourcing/drafting ran in a cloud Routine environment that physically had no `RESEND_API_KEY` in it, so even a successfully-injected unattended run couldn't have sent anything, the credential simply wasn't reachable. On 2026-08-23 Davide asked to merge the two Routines that existed briefly that day (one sourcing+drafting, one review+send) back into a single Routine for UI convenience, after being told explicitly what that costs: the single merged Routine's environment now holds `RESEND_API_KEY` alongside the web-browsing/sourcing capability, so the "never send unattended" rule is now enforced entirely by the prompt's Part A / Part B split (see "Routine status" below), not by credential absence. Davide made this call knowingly. If this skill is ever revisited and someone wants the harder guarantee back, split the Routine again and give the sourcing half no sending credential, per the 2026-08-22 design.

## Lead sourcing
- Real sources only: gym/studio websites, Google Maps listings, verified local business directories. Never invent or guess an email address or owner name (same hard rule as dental).
- **Segment mix (2026-09-02):** aim for roughly **40% CrossFit boxes / community boxes / boutique studios** (yoga, pilates, boxing, HIIT, strength) and **60% general gyms and fitness studios** — CrossFit/boutique boxes reply at a materially higher rate (5 of the first 6 genuine replies came from that segment). A mix preference, not a hard filter.
- Prefer independent studios and boutique gyms over big chains/franchises (same reasoning as dental: they decide faster, one owner to convince) — set `Studio Type` accordingly. This is an ordering preference, not a filter; chains still get added, just later in the queue.
- **Prefer leads with a clean confirmed `Owner/Manager` name AND a direct, non-generic email** (not `info@`/`hello@`/`enquiries@`) over generic-inbox-only leads (2026-09-02 "lever 1"). Still include generic-inbox leads, just later in the queue; the cold email adds a "please pass this to the owner" line for them (see "Current state"). Prefer any named `Owner/Manager` over blank/`VERIFY`.
- **Sourcing cap: up to 90 new leads per run** (raised from 60 on 2026-09-02); skip sourcing entirely if `Leads` already has 150+ unsent rows.
- Every new lead needs: Gym/Studio Name, City, Studio Type, Phone, Address, Email (confirmed from an actual source, mark `Email status` accordingly), Owner/Manager (name only if a clean confident source states it). Also fill `Instagram/Social` if a real handle/profile is findable from the studio's own website or a linked profile (never guessed) — this is for Davide/Abhi's own manual reach-out, this skill doesn't message it itself.
- Dedupe against `Send Log` before adding — never re-add or re-contact someone already emailed.
- Covers UK **and** EU, same markets as the rest of casdey's target (see CLAUDE.md "Business overview").
- **Write the `Phone` column as text, not a bare number** — Sheets' default value-input parsing will silently mangle it otherwise (a leading UK `0` gets dropped, e.g. `01612839296` → `1612839296`; a `+` international prefix can turn the whole cell into `#ERROR!`). Prefix the value with a literal apostrophe (`'01612839296`) when writing via the Sheets API, or write that column with `valueInputOption=RAW` and the apostrophe still included — either way, always re-read the row after an append and fix any mangled phone cells before finishing the run, don't assume the first write landed clean. (Caught and fixed live in the first real run, 2026-08-22 — see "Routine status" below.)

2. ## Fully automated sending
As of 2026-08-28 there is **no human approval gate** (see the banner under "Why this replaced the dental skill"). Part B runs automatically on every Routine fire, right after Part A. 1. **Assemble exactly 75** (fewer only if the drafted queue is genuinely exhausted, and never source more mid-run to top up). Order: due follow-ups first — FU1 then FU2, oldest due first, they count toward the 75 — then first-touch drafts with `Draft Status` = "Ready for review" and `Status` blank/"Not contacted", ordered by lever 1 (clean owner name AND/OR non-generic direct email first, then generic-inbox leads), oldest lead # first within each group.
2. **Hard pre-send gates — skip (do not send, leave `Draft Status` "Ready for review", record as skipped in the report) any draft that:** exceeds ~130 words; contains an em dash; contains any offer term (free week, Free plan, lifetime discount, a price/number-with-currency, the guarantee, scarcity) or the waitlist link — **note: variant B's light "free to try / set it up free" hook is ALLOWED and must not be skipped**; **asks "what would you pay" / "how much would you pay" / "which features" / "what features" (old copy, added as a gate 2026-09-03)**; has an empty subject or body; has a recipient already in `Send Log`; belongs to a lead whose `Status` is "Dead" or `Reply?` is "Unsubscribed"; or has a body byte-identical to another draft already in the day's batch (keep the first, skip the rest). If a first-touch draft is skipped, pull the next eligible one so the batch still targets 75 genuine sends.
3. Send each surviving email via `scripts/resend-send.js`. **Never more than 75 in a run, ever.**
4. Log every actual send immediately to `Send Log`: lead #, recipient, date, salutation type, opening line used, follow-up due date (4-5 calendar days out, skip to the next weekday if it lands on a weekend), the `Resend Email ID`, and `Variant` (`A`/`B` for first-touch, `FU1`/`FU2` for a follow-up). On an FU1 send also set that lead's `Follow-up 2 Due Date` (4-5 days out, next weekday); on an FU2 send set `Follow-up 2 Sent (Y/N)` → "Y".
5. Update `Leads`: `Status` → "Contacted", `Date Contacted`, `Draft Status` → "Sent"; for a follow-up also set the relevant `Follow-up Sent` flag.
6. If Step 0 (reply detection) failed on this run (missing creds or egress block), **still send the full 75** — Davide's explicit call, 2026-08-28. `Draft Status` = "Ready for review" is now a legacy label meaning only "drafted, not yet sent" — nobody reviews it.
